## Zustand 사용 가이드 (SSR/CSR)

기본 원칙:

- App Router 기준으로 **서버 컴포넌트 우선**으로 구성합니다.
- Zustand는 브라우저 상태(인터랙션/클라이언트 UI 상태)에 적합하므로, **스토어를 구독하는 컴포넌트는 `'use client'`** 이어야 합니다.

권장 패턴:

- `src/store/*Store.ts`로 도메인/관심사 단위 스토어를 분리합니다.
- 서버에서 필요한 데이터는 `app/` 레벨(서버 컴포넌트)에서 fetch 후 props로 내려주고, 클라이언트에서만 Zustand로 UI 상태를 관리합니다.
